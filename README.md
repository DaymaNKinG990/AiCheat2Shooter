# AiCheat2Shooter - AI Desktop Application

Современное десктопное приложение для AI анализа, построенное с использованием Flet framework.

## 🚀 Особенности

- **Современный UI**: Material Design 3 интерфейс с навигационной панелью
- **AI Анализ**: Множественные модели анализа с настраиваемыми параметрами
- **Управление файлами**: Полнофункциональная система управления файлами
- **Экспорт результатов**: Экспорт результатов анализа в различных форматах
- **Кроссплатформенность**: Работает на Windows, macOS и Linux
- **Горячая перезагрузка**: Быстрая разработка с мгновенным обновлением UI

## 📋 Требования

- Python 3.12+
- uv (менеджер зависимостей)

## 🛠️ Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd AiCheat2Shooter
```

2. Установите зависимости с помощью uv:
```bash
uv sync
```

3. Запустите приложение:
```bash
uv run main.py
```

## 🏗️ Архитектура

### Основные модули

- **main.py**: Главное приложение с UI интерфейсом
- **file_manager.py**: Система управления файлами
- **ai_analyzer.py**: AI анализ данных

### Структура проекта

```
AiCheat2Shooter/
├── main.py              # Главное приложение
├── file_manager.py      # Управление файлами
├── ai_analyzer.py       # AI анализ
├── pyproject.toml       # Конфигурация проекта
```

## 🎯 Функциональность

### Dashboard
- Обзор статистики приложения
- Последние действия
- Информация о файлах и анализе

### AI Analysis
- Загрузка файлов для анализа
- Выбор модели AI (default, advanced, custom)
- Пакетный анализ файлов
- Отображение результатов с метриками риска

- Настройка темы (светлая/темная)
- Выбор AI модели
- Конфигурация путей экспорта

### File Management
- Добавление файлов
- Создание папок
- Просмотр списка файлов
- Информация о файлах

## 🔧 AI Модели

### Default Model
- Базовый анализ с быстрой обработкой
- Определение уровня риска (low/medium/high)
- Обнаружение базовых паттернов

### Advanced Model
- Расширенный анализ с детальной оценкой
- Дополнительные метрики (behavioral, contextual)
- Критический уровень риска

### Custom Model
- Настраиваемый анализ с параметрами
- Гибкая конфигурация чувствительности
- Специализированные правила

## 📊 Метрики анализа

- **Confidence Score**: Уверенность в результатах (0-1)
- **Risk Level**: Уровень риска (low/medium/high/critical)
- **Complexity Score**: Сложность файла
- **Anomaly Score**: Аномальность содержимого
- **Threat Score**: Оценка угрозы

## 🚀 Разработка

### Добавление новых функций

1. Создайте новый модуль в соответствующей папке
2. Интегрируйте с главным приложением
3. Добавьте UI компоненты в main.py
4. Обновите документацию

### Структура UI компонентов

```python
def get_page_content(self):
    return ft.Column([
        ft.Text("Page Title", size=32, weight=ft.FontWeight.BOLD),
        ft.Divider(),
        # UI компоненты
        ft.Container(
            content=ft.Text("Content"),
            border=ft.border.all(1, ft.colors.OUTLINE),
            border_radius=8,
            padding=20
        )
    ])
```
