# 🎭 Task Orchestrator MCP Server

Полноценная ролевая система для управления задачами с использованием Model Context Protocol (MCP) и интеграцией с Trello.

## 🎯 Основные возможности

### 🎼 Роли системы:
- **Оркестратор** - главная роль, координатор всех процессов
- **Архитектор** - проектирование архитектуры и SOLID принципы
- **Кодер** - реализация задач, отладка, тестирование
- **Аналитик** - анализ, исследование через Context7
- **DevOps** - инфраструктура, CI/CD, конфигурация

### 🔄 Протокол переключения:
- Все переходы между ролями происходят через Оркестратора
- Роли не могут переключаться напрямую друг к другу
- После завершения работы роль возвращает управление Оркестратору

### 📝 Управление задачами:
- Создание и назначение задач
- Отслеживание статусов (TODO, IN_PROGRESS, REVIEW, DONE, BLOCKED)
- Управление зависимостями между задачами
- Git Branching Flow (Master → Release → Feature)

### 🔗 Trello Интеграция:
- Автоматическое создание карточек при создании задач
- Синхронизация статусов между системой и Trello
- Перемещение карточек между списками
- Обновление описаний карточек

### 💾 Локальное сохранение:
- Автоматическое сохранение задач в JSON файлы
- Работа системы без подключения к Trello
- Синхронизация данных при восстановлении подключения
- Резервное копирование всех данных

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
uv add create-mcp-server py-trello
```

### 2. Создание MCP сервера
```bash
uv run create-mcp-server
# Следуйте инструкциям для создания task-orchestrator-mcp
```

### 3. Настройка конфигурации
Обновите `c:\Users\xella\.cursor\mcp.json` согласно инструкциям в `MCP_SETUP_INSTRUCTIONS.md`

Перезапустите Cursor для применения изменений

## 🔧 Технические детали

### MCP Инструменты:
- `create_task` - создание задач (с опциональным созданием Trello карточки)
- `assign_task` - назначение задач ролям
- `complete_task` - завершение задач
- `switch_role` - переключение ролей
- `return_to_orchestrator` - возврат управления
- `get_status` - статус системы
- `list_tasks` - список задач
- `sync_to_trello` - синхронизация с Trello
- `export_tasks` - экспорт задач локально

### Интеграция:
- **Memory MCP** - сохранение контекста и истории
- **Context7** - исследование и документация
- **Git Branching Flow** - управление ветками
- **Trello API** - создание и управление карточками
- **Локальное JSON** - резервное сохранение данных

### Trello Списки:
- **To Do** - новые задачи
- **In Progress** - задачи в работе
- **Review** - задачи на проверке
- **Done** - завершенные задачи
- **Blocked** - заблокированные задачи

### Локальные файлы:
- **`tasks_backup.json`** - сохранение всех задач
- **`transitions_backup.json`** - сохранение переходов между ролями
- **Автоматическая загрузка** при запуске сервера
- **Автоматическое сохранение** при изменениях

## 🎯 Примеры использования

### Создание новой функции с Trello:
1. Оркестратор создает задачу → автоматически создается Trello карточка
2. Назначает Аналитику для исследования → карточка перемещается в "In Progress"
3. Аналитик возвращает управление
4. Оркестратор назначает Архитектору → карточка обновляется
5. Архитектор проектирует решение
6. Оркестратор назначает Кодеру
7. Кодер реализует функцию → карточка перемещается в "Done"
8. DevOps настраивает инфраструктуру

### Работа без Trello:
1. Оркестратор создает задачу → сохраняется локально
2. Система работает полностью автономно
3. Все данные сохраняются в JSON файлы
4. При восстановлении Trello можно синхронизировать данные

## 🔗 Trello Настройка

### Требуемые переменные окружения:
- `TRELLO_API_KEY` - ваш Trello API ключ
- `TRELLO_TOKEN` - ваш Trello токен
- `TRELLO_WORKING_BOARD_ID` - ID рабочей доски

### Автоматические действия:
- Создание карточек при создании задач
- Обновление статуса при изменении статуса задачи
- Перемещение между списками в зависимости от статуса
- Синхронизация описаний и метаданных

## 💾 Локальное сохранение

### Автоматические действия:
- Сохранение задач при каждом изменении
- Загрузка данных при запуске сервера
- Резервное копирование всех переходов
- Работа системы без интернета

### Файлы данных:
- **`tasks_backup.json`** - структурированные данные задач
- **`transitions_backup.json`** - история переходов между ролями

## 🚨 Устранение неполадок

### Trello не работает:
1. Проверьте токен согласно [TRELLO_TOKEN_SETUP.md](TRELLO_TOKEN_SETUP.md)
2. Запустите диагностику: `uv run python debug_trello_token.py`
3. Система продолжит работать локально

### Локальные файлы повреждены:
1. Удалите поврежденные файлы
2. Перезапустите сервер
3. Система создаст новые файлы

### Проблемы с MCP:
1. Проверьте конфигурацию в `mcp.json`
2. Убедитесь, что UV установлен
3. Перезапустите Cursor
